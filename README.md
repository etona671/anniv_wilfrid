# anniv_wilfrid

Une mini-application Web interactive créée spécialement
pour célébrer l'anniversaire de Yobo.

## Technologies

- HTML5
- CSS3
- JavaScript Vanilla

## Fonctionnalités

- Animation de démarrage système
- Terminal Linux simulé
- Effets lumineux
- Animation de confettis
- Galerie photographique
- Message personnalisé
- Interface responsive

## Installation

Cloner le dépôt :

```bash
git clone https://github.com/USERNAME/yobo-birthday.git
```
